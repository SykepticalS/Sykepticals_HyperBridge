# HyperBridge 0.6.0 — Sykeptical Edition

This release moves the Sykeptical Edition onto the official HyperBridge 0.6.0 development codebase. The notification reliability, messaging, call, screen-recording, VPN, diagnostics, and settings improvements previously maintained by this fork are now implemented upstream.

## What's new

- Replaced the previous fork code with the official HyperBridge 0.6.0 implementation.
- Added Xiaomi screen-recording Islands with live status, controls, and saved-state feedback.
- Added VPN Islands with connection-state updates and quick controls.
- Improved notification lifecycle handling, rapid-update ordering, message deduplication, and recovery.
- Improved call classification, session tracking, microphone state, timers, and contextual Island controls.
- Added the refreshed per-app configuration experience and expanded diagnostics.

## Sykeptical enhancement

- Added source app-icon badges to notification avatars, pictures, and large icons displayed inside Islands.
- Preserved full-colour app artwork and avoided duplicate badges when the displayed image is already the app or small notification icon.
- Continued using Xiaomi's native badge path for Island layouts that already provide one.

## Compatibility

Android 15 or newer is required. HyperOS system integrations depend on matching Xiaomi system components being available on the device.
