# HyperBridge 0.6.0-sykeptical

This release expands HyperBridge beyond app notifications with native system integrations and makes calls and fast-changing notifications more dependable.

## What's new

- Added Xiaomi screen-recording Islands with live recording status, a stop action, saved confirmation, and configurable expiration.
- Added VPN Islands that follow connecting, connected, reconnecting, paused, blocking, error, and disconnected states, with quick power and manage actions.
- Added a dedicated System section in the app library for enabling supported device integrations.
- Improved call classification and session tracking, including microphone state and contextual in-Island controls.
- Strengthened message-family tracking, duplicate suppression, update ordering, and lifecycle recovery during rapid notification changes.
- Expanded unit and device-test coverage for calls, messages, screen recording, VPN, presentation policy, and Island updates.

## Install

Download `HyperBridge-0.6.0-sykeptical-release.apk` below and install it over the previous Sykeptical Edition release.

Android 15 or newer is required. HyperOS system integrations depend on the matching Xiaomi system components being available on the device.
